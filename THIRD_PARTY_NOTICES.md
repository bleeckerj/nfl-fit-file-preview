# Third-party dependencies

FIT Preview uses Garmin's official FIT Swift SDK 21.217.0, under the [FIT Protocol License](https://github.com/garmin/fit-swift-sdk/blob/21.217.0/LICENSE.txt). The SDK depends on Apple Swift Collections, under the [Apache License 2.0 with Swift runtime library exception](https://github.com/apple/swift-collections/blob/main/LICENSE.txt).

Dependencies are fetched by Swift Package Manager. Their original license files remain in the package checkouts. The timestamp-expansion code follows the [Garmin FIT protocol specification](https://developer.garmin.com/fit/articles/fit-protocol/fit_protocol.html); it does not copy the OMATA Utility App parser.
